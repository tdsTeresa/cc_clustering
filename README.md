
<h2>💳 Descripción general:</h2>
<br>
El <b>clustering</b> es una técnica de aprendizaje no supervisado que agrupa datos en clusters según su similitud. En este proyecto se utiliza Scikit-Learn para aplicar algoritmos como K-Means, descubrir patrones y segmentar clientes.

<b> 
<h2>⚙️Tecnologías: </h2>
<br>
    • Python 3.10+<br>
    • Jupyter Notebook<br>
    • Pandas<br>
    • Numpy<br>
    • Matplotlib<br>
    • Seaborn<br>
    • Sklearn<br>
    • Scipy<br>
<br>

<h2>🧩 Variables:</h2
<br>CUST_ID, BALANCE, BALANCE_FREQUENCY, PURCHASES, ONEOFF_PURCHASES, INSTALLMENTS_PURCHASES, CASH_ADVANCE, PURCHASES_FREQUENCY, ONEOFF_PURCHASES_FREQUENCY, PURCHASES_INSTALLMENTS_FREQUENCY,  CASH_ADVANCE_FREQUENCY, CASH_ADVANCE_TRX, PURCHASES_TRX, CREDIT_LIMIT, PAYMENTS, MINIMUM_PAYMENTS, PRC_FULL_PAYMENT, TENURE.<br>

<br>
<h2>📊 Actividades: </h2>
<br>
    • Preparación de modelo de ML.<br>
    • Definición de modelo de clustering K-Means.<br>
    • Análisis de elementos gráficos como Heatmap, histograma, boxplot, dispersión de puntos.<br>
    • Transformación Yeo-Johnson y estandarización de datos (Zscore).<br>
    • Gráfico dendograma y evaluación.<br>
    • Evaluación del modelo (silhouette score).<br>

<br>
<br>
<h2>🟡 Resultados: </h2>
<br> 
     • Cluster 0: Compradores fecuentes con bajo uso de adelantos en efectivo.<br>
     • Cluster 1: Clientes más antiguos con bajo uso de adelantos en efectivo.<br>
     • Cluster 2: Clientes nuevos con alto uso de adelantos en efectivo.
